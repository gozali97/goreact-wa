# WA Proxy Platform — Task List

Architecture (adapted from PRD per arsitektur note):
- Backend: Go 1.24 + Gin + GORM + PostgreSQL + whatsmeow
- Realtime: WebSocket (QR, device status, new messages)
- Frontend: React + Vite + Tailwind + FlyonUI + React Router + TanStack Query + Zustand
- Single binary: Go serves REST + WebSocket + embedded React build (embed.FS)
- Deploy: `docker compose up -d` → services: `wa-proxy`, `postgres`

Goal: make the gateway more powerful while staying lightweight (no new infra).
- [x] X-Api-Key auth for the external messaging API (APIAuth middleware; Basic Auth fallback)
- [x] Outbound webhooks: HTTP POST with HMAC-SHA256 signature + bounded retries
      - events: message, message.ack, session.status
      - config: WEBHOOK_URL / WEBHOOK_SECRET / WEBHOOK_MAX_RETRY / WEBHOOK_EVENTS
- [x] Anti-blocking helpers (reduce ban risk):
      - POST /api/messages/check-exists (IsOnWhatsApp)
      - POST /api/messages/typing (SendChatPresence)
      - POST /api/messages/seen (MarkRead)
      - HUMANIZE_SEND: auto mark-seen + typing + random delay before SendText
- [x] API Docs page + .env.example updated with all new options
- [x] Backend build + vet clean; frontend build clean
